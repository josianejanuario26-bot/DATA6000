# DATA6000 – Energy Hardship Analysis in Australia

This repository contains the data, analytical models and documentation
developed for the DATA6000 project.

## Project Overview

The project investigates energy hardship across Australian Local Government
Areas (LGAs), combining socioeconomic, geographic and household-level data.

The analysis includes:

- Data preparation and transformation
- Exploratory data analysis
- LGA risk analysis
- K-Means clustering
- Machine learning prediction
- Power BI visualisation

## Repository Structure
